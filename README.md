# FIELD NOTES 2026 · 네이버 지도 + 자동재생 버전

## 변경 사항
- 기존 일러스트 지도 및 디자인 유지
- 기존 Google Maps 링크를 네이버 지도 검색/길찾기 링크로 변경
- 전체 경로 버튼은 네이버 지도 길찾기 화면을 엽니다. 출발/도착: 영주 여우생태관찰원, 경유: 주산지 → 월송정 → 한울에너지팜 순서로 사용자가 입력해야 합니다. 자동 경유지 설정을 보장하지 않습니다.
- 배경음악 자동재생 시도 및 음량 42%, 반복 재생. 브라우저에서 유음 자동재생이 차단되면 첫 클릭 또는 터치 시 자동 재시도. ▶ 버튼으로 직접 재생 가능.

## GitHub Pages 기존 홈페이지 교체
1. GitHub의 `fieldtrip-2026` 저장소에 들어갑니다.
2. **index.html** 파일을 열고 연필(Edit) 아이콘으로 파일 내용을 새 index.html 전체 내용으로 교체해 Commit changes를 누릅니다.
3. 기존에 `fieldtrip-theme.mp3`가 이미 있다면 다시 올릴 필요 없습니다. 없다면 MP3 파일을 저장소 최상단에 올리세요.
4. Pages 배포 후 새로고침(필요하면 Ctrl+F5)합니다. 기존 URL 그대로 유지됩니다.

## 참고
GitHub 웹의 Upload files는 기존 같은 이름의 파일을 덮어쓰지 못할 수 있습니다. 그 경우 파일 편집으로 교체하세요.
브라우저에서 소리 나는 자동재생을 100% 보장할 수 없습니다. 모바일과 일부 PC 환경에서 사용자 입력이 필요합니다.
네이버 지도의 검색 URL과 길찾기 화면은 외부 서비스이므로 제공 기능/주소가 향후 바뀔 수 있습니다.
