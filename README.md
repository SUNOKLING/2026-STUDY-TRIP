# 2026 선진지 견학 홈페이지 · 배경음악 추가 버전

## 업로드 (GitHub Pages)

기존 `fieldtrip-2026` 저장소의 최상단에 **index.html**과 **fieldtrip-theme.mp3** 두 파일을 함께 올리세요. 기존 index.html은 새 파일로 교체합니다. ZIP 파일 그대로 올리지 마세요.

- GitHub 저장소 → Add file → Upload files → 두 파일 드래그 → Commit changes
- 업로드 화면에서 교체가 되지 않으면 기존 index.html을 연 뒤 연필(Edit) 아이콘으로 코드를 교체하고, mp3 파일은 Upload files로 올리세요.
- Settings → Pages에서 기존 배포 설정 유지(`main` / `(root)`).
- 홈페이지에서 오른쪽 아래 `▶`를 누르면 배경음악이 시작됩니다. 음량 조절과 일시정지, 반복 재생이 가능합니다.

음악은 이 프로젝트를 위해 직접 합성한 오리지널 무보컬 연주곡이며, 타인 음원이나 기존 곡을 사용하지 않았습니다. 브라우저 정책상 소리가 나는 자동재생을 하지 않습니다.
