# 2026 견학 홈페이지 · 네이버 지도 전체 경로 버튼 수정본

## 수정 사항
- 기존 홈페이지, 음악, 빨간 점 애니메이션을 보존했습니다.
- 우측 아래 **네이버 지도에서 전체 경로 확인** 버튼을 교체했습니다.
- **스마트폰:** 네이버 지도 앱의 공식 `nmap://route/car` 연결 방식으로 출발지, 도착지, 경유지 3곳을 전달합니다. 네이버 지도 앱 설치 필요.
- **PC:** 코스 안내창과 네이버 지도 길찾기 링크를 제공합니다. PC 웹에서 경유지 자동 입력은 확인되지 않아 보장할 수 없습니다.
- 장소 위치 좌표는 시설 위치 공공데이터 기반입니다. 주산지의 자동차 주차장 진입 여부는 별도 확인하세요.

## GitHub 반영
1. `SUNOKLING/fieldtrip-2026` 저장소의 `index.html`을 새 파일로 교체 후 Commit changes.
2. MP3가 이미 있으면 업로드하지 않아도 됩니다.
3. `https://sunokling.github.io/fieldtrip-2026/`에서 강력 새로고침(Ctrl+F5).

## 참고
네이버 지도 웹에서 실제 전체 경로가 미리 선택된 **공유 URL**은 네이버 지도에서 길찾기를 직접 구성한 후 공유해야 얻을 수 있습니다. 본 수정본은 검증되지 않은 웹 공유 링크를 꾸며내지 않고 공식 앱 연결을 사용합니다.
