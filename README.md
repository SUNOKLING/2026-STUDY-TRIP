# 2026 자연환경해설사 선진지 견학 홈페이지

2026년 11월 30일(월) 당일 견학 홍보용 정적 웹사이트입니다.

## 코스
영주 여우생태관찰원(출발) → 청송 주산지 → 울진 월송정 → 울진 한울에너지팜 → 영주 여우생태관찰원(복귀)

## GitHub Pages 게시 방법
1. GitHub에서 새로운 **Public** 저장소를 만듭니다. 예: `fieldtrip-2026`.
2. 저장소 메인 화면의 `uploading an existing file` (빈 저장소) 또는 `Add file → Upload files`를 클릭합니다.
3. `index.html`과 `README.md`를 저장소 **최상위**에 업로드하고 Commit합니다. ZIP 파일 자체는 올리지 마세요.
4. `Settings → Pages → Build and deployment`에서 `Deploy from a branch`, 브랜치 `main`, 폴더 `/(root)`를 선택한 뒤 Save합니다.
5. 주소 형식: `https://사용자이름.github.io/fieldtrip-2026/`.

기존 mpliment 저장소가 아닌 **새 저장소**를 만드세요.

## 디자인/콘텐츠 유의사항
- 페이지의 루트 지도는 감각적인 **개념 노선도**이며, 실제 도로망·축척·이동 거리·시간을 나타내지 않습니다. 실제 지도 버튼은 Google Maps 길찾기 화면을 엽니다. 해당 경로는 지도 서비스가 다시 계산할 수 있으므로 출발 전 확인하세요.
- 방문·이동 시각은 제공되지 않아 표시하지 않았습니다.
- 여우생태관찰원은 **출발·복귀 집결지**로 표기했습니다. 일반 탐방은 월요일 휴관 안내가 있으므로 현장 운영 프로그램은 별도 확인이 필요합니다.
- 한울에너지팜의 홍보관 관람과 발전소/전망대 현장 견학은 조건이 다를 수 있으므로 사전 협의가 필요합니다.
- 별도 서버, DB, 빌드 도구는 필요하지 않습니다.
- 글이나 날짜를 바꾸려면 `index.html`에서 수정합니다.
