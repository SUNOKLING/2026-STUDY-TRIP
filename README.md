# 2026 선진지 견학 · 빨간 위치 점 이동 버전

## 업데이트
- 원래의 지도, 점선, 장소 이름, 음악 플레이어, 네이버 지도 링크를 유지했습니다.
- 빨간 위치 표시 점이 19초마다 영주(S) → 주산지(1) → 월송정(2) → 한울에너지팜(3) → 영주(S) 순서로 계속 돌아옵니다.
- 실제 이동 시간/도로와 무관한 **홍보용 애니메이션**입니다.
- 기기의 ‘움직임 줄이기’ 설정을 사용하면 점이 정지합니다.

## GitHub 반영
1. 기존 저장소 `SUNOKLING/fieldtrip-2026`로 이동합니다.
2. `index.html`을 열고 편집(연필 아이콘)을 클릭합니다.
3. 이 폴더의 `index.html` 내용을 기존 파일 전체와 교체하고 Commit changes를 누릅니다.
4. `fieldtrip-theme.mp3`는 이미 올라가 있다면 다시 올릴 필요 없습니다. 빠져 있다면 저장소 최상단에 함께 업로드하세요.
5. 사이트 `https://sunokling.github.io/fieldtrip-2026/`에서 확인하고 변화가 보이지 않으면 강력 새로고침(Ctrl+F5)을 해보세요.
