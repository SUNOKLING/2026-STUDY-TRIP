# 2026 선진지 견학 홈페이지 — 상단 음악 플레이어 버전

- 메인 제목 아래에 크게 보이는 음악 재생 카드
- ▶ 클릭 시 연주곡 시작, 사이트를 스크롤해도 음악 지속
- 진행률, 재생시간, 음량 조절, 반복 재생
- 네이버 지도 검색 및 경로 버튼 유지
- 자동재생 시도 제거 (브라우저 차단 방지)

## GitHub Pages 반영
1. 기존 `fieldtrip-2026` 저장소에서 `index.html`을 열어 연필 아이콘(Edit)을 클릭합니다.
2. 수정본 `index.html` 내용을 전체 복사해 붙여넣고 Commit changes를 누릅니다.
3. 저장소 최상단에 `fieldtrip-theme.mp3`가 이미 있으면 추가 업로드할 필요가 없습니다. 없는 경우 파일을 업로드합니다.
4. 기존 GitHub Pages 주소에서 새로고침합니다.

참고: `index.html`과 `fieldtrip-theme.mp3`는 저장소 루트에 함께 위치해야 합니다.
